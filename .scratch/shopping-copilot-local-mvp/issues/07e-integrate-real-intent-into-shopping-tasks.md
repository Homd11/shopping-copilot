# 07E — Integrate real intent into Shopping Tasks

**What to build:** Make the pinned real model the local development interpreter while preserving deterministic fast paths, task control, recovery, and every existing safety invariant.

**Blocked by:** None. 07D is resolved by the documented local-development baseline decision.

**Status:** resolved

- [x] The live Agent uses validated model intent rather than hardcoded vocabulary for unfamiliar Shopper wording.
- [x] Completely understood Constraints still use one deterministic direct-navigation fast path after validation.
- [x] Provider failure pauses the same task with visible Retry and Stop choices; it never silently changes provider or falls back to the scripted client.
- [x] The Panel shows honest staged status while interpretation is pending and keeps Stop available without fake progress percentages.
- [x] Retrying creates a new model-call identity while preserving normalized task state and never replaying an uncertain browser Action.
- [x] Ordinary tests and CI remain network-free; recorded real-model browser evaluation requires explicit opt-in and records provider metadata.
- [x] Three previously unseen owner-written requests—one Egyptian Arabic, one Franco-Arabic, and one mixed-language—complete through the browser without adding their wording to a keyword list.
- [x] A fixed-origin read-only catalogue interface exposes public fixture facts, including features, suitability, availability, and EGP price, without an Agent-side product copy or database.
- [x] The Intent Boundary preserves catalogue-recognized use, material, style, size, color, and price preferences or explicitly leaves them unresolved; the wedding request cannot degrade to black shoes while claiming an Exact Match.
- [x] The Panel shows up to three verified products with concise reasons and distinct Exact Match, Alternative, or Styling Suggestion labels; absent evidence never becomes a match claim.
- [x] The Franco-Arabic browser evaluator checks Agent completion events and Storefront outcome independently of localized status copy.
- [x] Existing deterministic browser, refresh, lease, Stop, stale-result, currency, and safety regressions remain green.
