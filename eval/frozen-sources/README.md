# Historical catalogue source

The `.txt` artifact is the exact normalized-LF `store/src/catalogue.ts` from
commit `12d36f7`, before the SQLite migration. Its SHA-256 is its filename and
matches the existing CAP-02/03 release manifests. It is data for reproducibility,
never imported or executed by the application.

Only that historical catalogue path may resolve to this hash-verified archive.
Annotation, split, context and result files retain their original strict checks;
none of their frozen bytes or hashes were changed.
