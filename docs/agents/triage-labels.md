# Triage Labels

The engineering skills use these five canonical triage roles as local issue statuses.

| Canonical role    | Local status      | Meaning                                   |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | The issue needs evaluation                |
| `needs-info`      | `needs-info`      | More information is required              |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent    |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix`         | `wontfix`         | Will not be actioned                      |

When a skill mentions a triage role, use the corresponding local status exactly as written.
